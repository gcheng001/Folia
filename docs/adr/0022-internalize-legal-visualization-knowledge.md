# 内化 legal-visualization 知识而不开放特权 Skill 通道

已接受（2026-07-17）。Folia 与 legal-visualization Skill（cat-xierluo/legal-skills）同属一位作者，该 Skill 仓库是法律制图方法论——场景路由、场景库、编排规则、法律视觉常量与图型规范——的上游权威。Folia 沿既有「Skill 模板」与「抽取规格」机制，把这些知识提炼固化为随版本发布的资源：场景路由知识进入视图推荐与生成提示词，子进程保持零工具权限并继续只输出结构化数据；编排规则与视觉常量翻译为本地布局与样式实现；场景库按六大视图家族逐批落为新模板。备选方案「由全权限 claude 运行完整 Skill 直接产出 draw.io 成品」被拒绝：办案源材料常含对方当事人文书，对子进程开放文件与命令权限会把提示词注入从理论风险变成现实攻击面，且 .drawio 成品绕开可编辑 Skill SVG 的既有编辑、质检与版本投资。代价是渲染质量的提升必须等待布局引擎逐步吸收视觉规则，不能立即达到 draw.io 的成熟渲染水平；许可层面因两个项目作者同一而不构成约束，Skill 对外的 CC-BY-NC 条款不影响作者本人在 Folia 中复用其内容。
