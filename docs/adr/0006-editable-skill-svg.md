# Skill 成品图把编辑信息保存在同一个 SVG 中

已接受并由 ADR 0009 补充（2026-07-13）。Skill 成品图第一版仍是静态 SVG；第二版不新增并列的工程文件，而是在同一个 SVG 中保存由 Folia 识别的文字、方框、尺寸和连接关系，使普通看图软件仍能直接显示成品，Folia 则能恢复编辑状态。原生可编辑 SVG 只从 Folia 自有、版本化编辑信息恢复场景；普通旧 SVG 不直接猜测后原地编辑，但可以按 ADR 0009 复制并升级为外观优先的可编辑副本。

**Consequences**

- 第二版可以修改文字、移动方框、调整大小，并让连接线自动跟随。
- 第二版可以新增、删除方框和连接线，用于补充遗漏内容、移除多余内容和修正错误关系。
- 第二版可以调整单个方框和连接线的有限样式，但字体保持整图统一，避免编辑后失去视觉一致性。
- 第二版同时提供保留手动修改的“优化当前图”和从源文档重新绘制的“重新生成”，两种操作都产生新版本。
- 编辑信息必须版本化、经过严格校验，并不得包含源文件绝对路径或不必要的原文内容。
- 打开普通外部 SVG 时先按只读图片处理；用户主动选择后，可按 ADR 0009 升级为不覆盖原件的可编辑副本。
- 导出或分享时可以保留编辑信息，也应提供移除编辑信息的纯成品导出。
