# Skill 成品图作为可编辑工作簿之外的平行路径

已接受（2026-07-13）。Folia 新增以视觉质量优先的 **Skill 成品图** 路径，第一版只接入经过审查并锁定版本的 `baoyu-diagram`；生成结果用于查看、导出和重新生成，不承诺在 Folia 中逐个编辑图形元素。它与可编辑 `.foliaviz` 工作簿并存：前者解决“生成得漂亮”，后者解决来源追溯和逐项编辑。该决定收窄 ADR-0003 与 ADR-0004 中“不运行 Skill”的限制：Folia 仍不执行用户机器上任意来源的 Skill，也不把 Skill 成品反向解析成工作簿，但允许通过应用外的 Agent 调用随 Folia 审查、锁版且许可明确的可视化 Skill。

**Consequences**

- 第一版实施前必须先用真实法律文档证明视觉效果，并确认 Skill 的分发许可。
- Skill 成品图必须使用准确的联网与隐私提示，生成时支持进度、取消和旧文件保护。
- 第一版保持静态成品；第二版的逐项编辑改为在同一个 SVG 中保存 Folia 编辑信息，见 ADR-0006。`.foliaviz` 工作簿仍作为另一条可编辑路线保留。
