# PRD：一键可视化工作簿

## 目标

用户在 Folia 打开一份 Markdown 后，点击“一键可视化”，即可由完全本地、离线、确定性的规则引擎推荐并生成一份独立可编辑的可视化工作簿。可视化结果不改写 Markdown；用户只有明确执行“同步修正原文”并确认差异时，才会修改来源文档。

## 核心原则

1. **Markdown 是事实来源，`.foliaviz` 是独立成果。** 布局、简称和展示文字只存在于工作簿。
2. **本地确定性。** 不调用网络、外部 Agent 或本机已安装 Skill；相同内容与规则版本产生相同推荐。
3. **可解释推荐。** 匹配度必须展示命中信号、缺失字段和待确认项，不输出黑箱分数。
4. **可追溯，不编造。** 正式元素必须绑定原文来源；推测关系只能进入待确认侧栏。
5. **人工补充有身份。** 无来源内容允许作为“视图注释”，但不得伪装成原文事实。
6. **增量同步。** 外部 Markdown 变化必须审阅后合并，保留人工布局和展示覆盖。
7. **交付净化。** PNG、SVG、PDF、HTML 不泄露本机路径、指纹、内部 ID、撤销历史或未显示原文。

## 用户流程

1. 用户打开 Markdown，点击由原脑图入口升级的“一键可视化”。
2. 视图路由器评估候选视图：高匹配度时直接生成主视图；低匹配度时先展示 2～3 个候选及理由。
3. 可视化工作簿占据主编辑区，页签栏展示主视图、推荐添加项和“更多类型”。
4. 用户可以编辑文字、布局、节点、连线、表格和样式。普通编辑默认只改变工作簿。
5. 用户发现原文错误时，从元素执行“同步修正原文”，查看 Markdown 差异并确认回写。
6. 首次保存创建同目录、同名 `.foliaviz`；以后自动保存。一本工作簿绑定一份 Markdown，可包含多个视图页签。
7. 用户导出当前页或整本工作簿。

## 首版视图家族

| 家族 | 典型信号 | 典型法律模板 | 渲染方式 |
|---|---|---|---|
| 结构总览 | 标题层级、列表层级 | 文档大纲、争议焦点树 | 复用 React Flow 脑图 |
| 时间轴 | 日期、时间、事件、证据邻接 | 案件事实时间轴、程序时间轴 | 可编辑 HTML 时间表/卡片 |
| 关系网络 | 主体、显式关系词、定向流转 | 人物关系、资金流向 | React Flow 节点画布 |
| 流程与决策 | 编号步骤、先后词、条件分支、状态 | 程序流程、决策树 | React Flow 节点画布 |
| 矩阵与对比 | 多对象共享字段、表格、印证/矛盾 | 证据矩阵、主体对比 | 可编辑 HTML 表格/卡片 |
| 数值图表 | 明确数值、分类、时间序列 | 金额对比、数量趋势 | 轻量 SVG 柱状/折线/饼图 |

结构总览是缺少其他强信号时的可靠兜底。资金流向、证据矩阵等属于视图类型或模板，不另造渲染器。

## 推荐与抽取

每个视图家族声明自己的数据契约、最低门槛、信号权重和完整性校验。匹配度由覆盖率、字段质量、可排序/可连通比例和歧义惩罚共同形成。高匹配度直接生成并展示备选；低匹配度先选择。具体阈值由 fixture 校准并固定在版本化规则中。

抽取结果统一进入结构化中间表示（SIR）。每个正式事件、节点、边或数据项必须携带来源锚点；无法证明的隐含关系不得自动进入正式 SIR。

## 编辑与来源同步

- 普通双击编辑产生展示覆盖，不修改 Markdown。
- “同步修正原文”展示精确差异，用户确认后才替换来源片段。
- 来源锚点至少保存原始摘录、摘录指纹和位置提示；回写前必须重新校验。
- 原文外部变化后，工作簿展示新增、修改、删除和来源失效四类差异。
- 来源失效元素由用户删除、保留为视图注释或重新绑定。
- 视图注释可后续绑定 Markdown，升级为可追溯元素。

## `.foliaviz` 文件

`.foliaviz` 是带 `schemaVersion` 的 JSON 文件，至少保存：相对来源路径、源内容指纹、规则版本、工作簿元数据、页签、SIR、来源锚点、展示覆盖、布局、待确认项、导出设置和必要的可迁移历史。不得保存外部 Skill 代码。

生成时先创建内存草稿；首次保存默认使用源 Markdown 同目录、同名文件。正式保存后自动保存。来源路径失效时允许重新绑定；首版不支持一本工作簿绑定多份 Markdown。

## UI 与设计

- 现有脑图按钮升级为“一键可视化”；直接点击自动路由，小菜单手动选择类型。
- 工作簿使用完整主编辑区，不作为右侧狭窄预览面板。
- 工作簿顶部只放页签、推荐依据、保存/导出和返回 Markdown 等当前任务操作。
- 遵循 Folia 暖调纸面、单一 `--accent`、2～5px 圆角、低投影和渐进展示原则。
- 待确认、来源失效和人工注释优先用线型、图标和文字区分，不建立第二套大面积强调色。

## 导出

- 当前页：PNG；适用家族支持 SVG。
- 当前页或全部页：PDF。
- 整本：独立只读 HTML，保留页签切换、缩放和说明交互。
- `.foliaviz` 是唯一保留编辑和来源同步能力的格式。
- 时间轴与矩阵优先 HTML/PDF/PNG，不强求 SVG。
- 首版不直接导出 Word。

所有成品导出必须经过交付净化；只有用户显式开启“显示来源引用”时才导出可见原文摘录。

## 模板扩展

首版仅提供内置模板。未来只允许导入声明式模板包，用于描述视图家族、字段映射、识别词、布局参数、配色、图例和最低门槛；禁止执行 JavaScript、外部 Skill 或其他脚本。复杂抽取逻辑必须随 Folia 版本发布。

## 验收标准

- 离线状态下对同一 Markdown 重复执行，推荐顺序和解释完全一致。
- 高匹配时间文档能生成可编辑时间轴；普通标题文档至少能生成结构总览。
- 正式元素均可定位原文；推测关系不会未经确认进入正式视图。
- 普通视图文字编辑不改变 Markdown；“同步修正原文”必须先显示差异并校验锚点。
- Markdown 外部变化不会覆盖人工布局或展示覆盖，且能审阅四类增量差异。
- `.foliaviz` 可保存、重新打开、移动后重新绑定来源并继续编辑。
- PNG/SVG/PDF/HTML 按家族能力导出；成品中不存在绝对路径、内容指纹和内部 ID。
- 现有脑图编辑能力在结构总览页签中保持可用。

## 首版不包含

- 网络模型、云端 AI、本地大模型或运行时 Agent/Skill 调用。
- 多源 Markdown 合并与跨文档实体消歧。
- 直接导入可执行模板或现有 Skill。
- Word、PPTX、视频导出。
- 对无原文依据关系的自动法律推断。
