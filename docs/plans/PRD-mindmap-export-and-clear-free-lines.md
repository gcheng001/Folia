# PRD - 脑图导出修复 + 一键清除手动画线

- 日期：2026-07-12
- 来源：用户实测反馈，基于当前 v0.4.7 本地构建版脑图画布
- 触发标签：ready-for-agent
- 目标仓库：gcheng001/Folia（当前可写 origin）
- Published Issue：https://github.com/gcheng001/Folia/issues/2

## Problem Statement

用户正在用 Folia 的脑图画布整理法律文档和流程图。上一轮已经加入了“无连接线”模式下的自由箭头/线段能力，但真实试用后还有两个阻塞点：

1. **导出功能仍不可用**：用户在脑图画布中完成节点、自由箭头和线段整理后，期望导出 PNG/PDF 作为可交付流程图或汇报图，但当前导出仍失败。对用户来说，这意味着画布虽然能编辑，却无法形成最终成果。
2. **缺少一键清除手动画线**：现有“无连接线”只隐藏自动父子连接线，不会清除用户自己画出来的自由箭头/线段。用户画了很多流程线后，如果想重新整理，只能逐条选中删除，效率很低，也容易漏删。

用户需要的是：导出必须真正可用；同时新增一个明确的“一键清除”入口，只清除自己手画的自由箭头/线段，不影响节点、自动连接线设置、节点连接线和标注框。

## Solution

从用户视角：

1. 脑图画布的导出 PNG/PDF 能稳定完成。无论画布里有没有自由箭头、自由线段、节点连接线、标注框、节点颜色和节点尺寸，导出都应成功，并且导出结果包含用户看到的主要内容。
2. 导出失败时，用户看到的是清晰、可理解的错误提示，而不是静默失败或泛泛的“失败”。
3. 工具栏新增一个“一键清除手动画线”入口，用于清除所有自由箭头/线段。
4. “去连接线/无连接线”继续只控制自动父子连接线显示；“一键清除”专门处理用户手画的自由箭头/线段。
5. 清除动作可撤销。用户误点后可以通过撤销恢复刚才的自由箭头/线段。
6. 一键清除不删除脑图节点、不删除节点连接线、不删除标注框、不改变节点颜色和尺寸、不改变自动连接线模式。

## User Stories

1. As a 律师用户, I want 脑图画布能导出 PNG, so that 我可以把整理好的流程图直接放进汇报材料或聊天沟通中。
2. As a 律师用户, I want 脑图画布能导出 PDF, so that 我可以把整理好的结构图作为正式附件或打印材料使用。
3. As a 律师用户, I want 导出结果包含我手画的自由箭头, so that 我表达的流程方向不会在输出文件里丢失。
4. As a 律师用户, I want 导出结果包含我手画的普通线段, so that 我手工整理的流程关系能被完整保留。
5. As a 律师用户, I want 导出结果包含节点颜色和节点尺寸, so that 输出图与画布里看到的视觉重点一致。
6. As a 律师用户, I want 导出结果包含节点连接线, so that 我手工补充的节点到节点关系不会丢失。
7. As a 律师用户, I want 导出结果包含标注框, so that 我圈出的证据组、事实组或争点组能出现在输出文件里。
8. As a 律师用户, I want 导出范围自动覆盖全部可见画布内容, so that 边缘的箭头或线段不会被裁剪。
9. As a 律师用户, I want 导出时不包含工具栏、选择框、连接点和蓝色选中光晕, so that 输出图看起来像正式成果而不是编辑界面截图。
10. As a 律师用户, I want 导出失败时看到明确原因, so that 我知道是保存路径、权限、画布渲染还是其他问题导致失败。
11. As a 律师用户, I want 导出失败后画布内容不受影响, so that 我不会因为一次失败丢掉刚才整理的流程图。
12. As a 律师用户, I want 在“无连接线”模式下也能成功导出我手画的箭头和线段, so that 我可以用 Folia 做真正的流程图输出。
13. As a 律师用户, I want 有一个“一键清除手动画线”按钮, so that 我画乱之后可以快速重来。
14. As a 律师用户, I want 一键清除只删除自由箭头和自由线段, so that 我的脑图节点和结构不会被误删。
15. As a 律师用户, I want 一键清除不改变“无连接线/脑图线/流程箭头”的自动连接线模式, so that 清理手动画线不会改变整体视图设置。
16. As a 律师用户, I want 一键清除不删除节点连接线, so that 我明确从节点连到节点的关系仍然保留。
17. As a 律师用户, I want 一键清除不删除标注框, so that 我已经圈选出的分组关系不会被破坏。
18. As a 律师用户, I want 一键清除不改变节点颜色, so that 我对重点节点做的颜色标记不会丢失。
19. As a 律师用户, I want 一键清除不改变节点尺寸, so that 我对重点层级做的大小区分不会丢失。
20. As a 律师用户, I want 一键清除可以撤销, so that 误操作后能马上恢复线段和箭头。
21. As a 律师用户, I want 清除后上下文样式栏自动消失或切回合理状态, so that 不会显示一个已经不存在的线段样式面板。
22. As a 律师用户, I want 清除后导出结果不再包含被清除的自由线, so that 输出文件反映当前画布状态。
23. As a 律师用户, I want 画布没有自由线时“一键清除”不会报错, so that 我可以放心点击。
24. As a 律师用户, I want “去连接线”和“一键清除”在文案上容易区分, so that 我不会误以为它们是同一个功能。
25. As a 律师用户, I want 完成修复后新版应用直接替换本地旧版, so that 我打开应用就能试到修复结果。

## Implementation Decisions

- 导出修复优先按真实用户路径复现：画布中同时存在节点、自由箭头、自由线段、节点连接线、标注框、节点颜色和节点尺寸时，PNG/PDF 导出必须成功。
- 导出范围以画布内容包围盒为准，纳入节点、自动边、节点连接线、标注框和自由线端点。自由线端点既可能是自由端点，也可能是绑定端点；绑定端点应按当前节点位置解析。
- 导出时应继续隐藏编辑态 UI，包括工具栏、缩放控件、连接点、选择框、选中光晕和编辑输入框。
- 导出错误提示保留用户可理解信息。保存路径取消不视为失败；真实渲染、写文件或权限错误需要提示。
- “无连接线”仍只表示隐藏自动父子连接线，不承担删除数据的语义。
- 新增“一键清除手动画线”入口，作用对象是 sidecar 中的自由流程线集合。
- 一键清除不删除节点连接线，因为节点连接线表达的是从一个节点到另一个节点的用户自定义关系，与自由画线不是同一类对象。
- 一键清除动作必须进入画布历史栈，可通过撤销恢复，通过重做再次清除。
- 清除后应清理当前选择集合中已不存在的自由线 id，避免样式栏指向不存在对象。
- 工具栏入口应使用明确文案和 tooltip，避免与“无连接线”混淆。建议文案为“清除手动画线”或“清除箭头/线段”。
- 完成后需要写入用户可见变更记录，并构建安装到本地应用目录。

## Testing Decisions

- 测试只断言用户可见行为和持久状态，不断言内部函数调用顺序。
- 最高测试接缝为脑图画布组件级行为测试：预置/创建自由箭头和自由线段后，点击“一键清除手动画线”，断言自由线集合清空，同时节点、节点连接线、标注框、颜色、尺寸和自动连接线模式保持。
- 清除行为需要覆盖撤销/重做：清除后撤销可恢复自由线，重做可再次清除。
- 导出链路需要组件级或服务级测试覆盖：导出 bounds 包含自由线端点和标注框；克隆导出 DOM 时隐藏编辑态 UI；导出失败会触发可理解提示。
- 优先复用已有脑图功能测试和导出 helper 测试，不新增低层测试接缝，除非复现真实导出失败需要抽出一个更可控的保存/渲染适配层。
- 回归测试应覆盖“无连接线模式 + 手画自由线 + 导出”，因为这是用户明确反馈的核心场景。
- 完整验证命令包括类型检查、目标脑图测试、全量测试、本地 Tauri 构建；构建成功后替换本地应用并校验 hash。

## Out of Scope

- 不重新设计整个脑图导出 UI。
- 不新增批量清除节点、标注框或节点连接线的功能。
- 不把“一键清除”做成多选清理菜单或复杂对象管理器。
- 不实现导出 SVG、Word 或图片编辑能力。
- 不改变 Markdown 源文档结构。
- 不改变自由画线的吸附、绑定、规整和节点尺寸既有决策，除非它们被证明是导出失败的直接原因。

## Further Notes

- 用户明确区分了“去连接线”和“清除手动画线”：前者是显示模式，后者是删除用户手工绘制对象。
- 导出不可用是阻塞性缺陷，应优先于新增清除按钮完成。
- 当前工作树已有上一轮脑图画布增强的未提交实现；执行时不得回退这些相关改动，应在现有基础上补齐缺陷。
- 若修复发现导出失败来自 Tauri 保存 API、html2canvas 克隆、React Flow viewport transform 或 SVG marker 渲染，需要在 PR/交付说明中明确根因。
