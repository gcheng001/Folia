# 脑图画布自由流程线与一键规整计划

## 背景

用户希望在脑图画布中像流程图工具一样自由添加箭头或线段，而不是只能从一个节点连到另一个节点。现有“连接模式”基于节点连接线，source/target 必须绑定节点，导致线段长短、方向和可控性都取决于节点位置，无法满足流程图整理和导出的使用场景。

本计划使用项目词表中的术语：自由流程线、自由端点、绑定端点、吸附、画布规整、节点尺寸档位。

## 已确认的产品决策

- 新增“自由流程线”：端点可以落在画布任意位置。
- 自由流程线端点支持两种语义：
  - 自由端点：只保存画布坐标。
  - 绑定端点：端点吸附并绑定到节点锚点，节点移动时端点跟随。
- 拖动时默认启用吸附：
  - 靠近节点边缘时吸附到节点锚点。
  - 吸附到水平、垂直、45°方向。
  - `Option/Alt` 临时关闭吸附。
  - `Shift` 强制水平、垂直、45°。
- 工具栏将“连接模式”升级为“画线工具”：
  - 默认“箭头”：拖拽创建单向自由流程线。
  - “线段”：拖拽创建无箭头自由流程线。
  - “节点连接”：保留现有节点到节点连接能力，作为兼容/高级路径。
- 新增“画布规整”：
  - 默认作用于当前选中对象。
  - 没有选中对象时作用于整张画布。
  - 规整是确定性算法，不接入外部 AI。
- 画布规整能力：
  - 一键对齐节点。
  - 一键统一自由流程线长短。
  - 一键统一自由流程线方向。
  - 一键统一箭头/线段样式。
- 箭头/线段样式统一规则：
  - 多数是箭头，则统一为箭头。
  - 多数是无箭头线段，则统一为线段。
  - 数量打平时不强行改箭头样式。
  - 样式栏仍允许用户显式选择单向、双向、无箭头。
- 方向规整规则：
  - 单条线按当前角度吸附到水平、垂直或最近 45°。
  - 多条线取多数方向作为统一方向。
  - 方向很分散时只做端点吸附和长度统一，不强行全部改为一个方向。
- 节点尺寸使用 5 档：
  - XS：辅助说明
  - S：次要节点
  - M：默认
  - L：重点节点
  - XL：核心节点
- 节点尺寸是单个节点样式，保存在 sidecar，不改 Markdown。

## 建议实现切面

### 数据模型

- 在脑图 canvas sidecar 中新增自由流程线集合。
- 每条自由流程线包含：
  - id
  - start endpoint
  - end endpoint
  - arrow style：单向、双向、无箭头
  - shape：直线、折线（后续可扩展）
  - dash：实线、虚线
  - color
  - width
- endpoint 支持：
  - kind = free：保存 x/y。
  - kind = bound：保存 node position key、anchor、offset 或 resolved point。
- 节点样式扩展 5 档 sizeLevel，与现有 color 共同作为 per-node style。

### 交互

- 画线工具处于“箭头”或“线段”时：
  - pointer down 在画布或节点上开始创建自由流程线。
  - pointer move 显示预览线，并应用吸附。
  - pointer up 完成创建。
  - 如果端点靠近节点锚点且未按 Option/Alt，则保存为绑定端点。
  - 如果按 Option/Alt，则保存为自由端点。
- 画线工具处于“节点连接”时，沿用现有节点到节点连接行为。
- 自由流程线可选中、删除、改色、改箭头样式、改线型。
- 自由流程线端点后续应可拖动调整。

### 画布规整

- 新增“一键规整”命令。
- 输入对象：
  - 当前选中的节点和自由流程线。
  - 如果没有选中，则取整张画布中的节点和自由流程线。
- 节点规整：
  - 复用已有对齐/等间距能力作为第一阶段。
- 自由流程线规整：
  - 计算方向分类：水平、垂直、45°、其他。
  - 多条线取多数方向。
  - 将线段投影到目标方向。
  - 统一长度时优先使用选中线段长度的中位数，避免极端值影响。
  - 保持线段中心点不动，调整两端点。
  - 绑定端点需要重新解析到节点锚点，避免规整后脱离节点。
- 样式规整：
  - 箭头/线段采用多数决。
  - 颜色和宽度第一阶段不自动多数决，避免误改语义颜色。

### 节点尺寸档位

- 在选中节点时的上下文样式栏增加尺寸档位控件。
- 多选节点时：
  - 如果尺寸一致，显示当前档位。
  - 如果尺寸不一致，显示混合状态，点击任一档位批量应用。
- 尺寸影响节点宽高、padding、字体大小，但不改变 Markdown。
- 导出应反映节点尺寸。

## 测试策略

- 最高优先使用脑图画布功能测试覆盖用户行为。
- 新增 sidecar 单测覆盖自由流程线和节点 sizeLevel 的读写与兼容。
- 新增纯函数测试覆盖：
  - endpoint 吸附规则。
  - 方向分类。
  - 线段长度统一。
  - 多数决箭头/线段样式统一。
- 组件测试覆盖：
  - 画线工具默认创建自由箭头。
  - 线段工具创建无箭头自由流程线。
  - Option/Alt 创建自由端点。
  - 靠近节点创建绑定端点。
  - 一键规整只作用于选中对象；无选择时作用于整张画布。
  - 节点尺寸档位保存后取消选择、重开文档仍生效。
- 回归检查：
  - `npm run typecheck`
  - 目标脑图测试
  - 全量 `npm test -- --run --reporter dot`
  - `npm run tauri:build:local`

## 暂不纳入

- 外部 AI 或联网模型自动排版。
- 任意曲线、贝塞尔编辑器或完整矢量绘图工具。
- Markdown 内编码流程线。
- 自动识别文档语义并生成流程图。
